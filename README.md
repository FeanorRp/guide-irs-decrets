# Guide IRS - San Andreas (version décrets)

Guide de l'Internal Revenue Service de l'État de San Andreas, intégrant les décrets de la Mairie en vigueur : décrets, code entreprises, code citoyen, grille des salaires, impôts, fiscalité, droits du contribuable, organisation de l'IRS, extraits du code pénal, calculateur d'amendes et assistant de recherche.

Deux zones : `sud/` (guide + décrets de la zone Sud) et `nord/` (guide + décrets de la zone Nord). La page racine `index.html` permet de choisir la zone.

Site statique, sans compilation : ouvrir `index.html` ou le publier via GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root).

Dans chaque zone, le contenu du guide se trouve dans `assets/data.js` et les réponses de l'assistant dans `assets/intents.js`.
